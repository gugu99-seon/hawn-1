# 인터뷰 작업 지침

## 작업 순서

1. 인터뷰 질문지를 작성하고 실제 인터뷰 녹음파일을 받는다. 질문지와 녹음파일은 `00입력/질문지/`, `00입력/녹음파일/`에 저장한다.
2. 녹음파일을 기준으로 실제 인터뷰를 전사하고 정리한다. 결과는 `1. 구두 인터뷰 정리 방법/` 단계에서 관리한다.
3. 실제 인터뷰에서 확인된 내용을 토대로 가상인물을 만들고 인터뷰 질문을 준비한다. 관련 프롬프트와 산출물은 `2. 가상인물 인터뷰 생성 프롬프트/`에서 관리한다.
4. 가상인물 인터뷰를 진행한다. 관련 프롬프트와 산출물은 `3. 가상인물 인터뷰 진행 프롬프트/`에서 관리한다.
5. 인터뷰 내용을 근거로 브랜딩을 기획한다. 관련 프롬프트와 산출물은 `4. 인터뷰 기반 브랜딩 기획 프롬프트/`에서 관리한다.
6. 브랜딩 기획 보고서를 Markdown 파일로 작성하고 `5. 브랜딩 기획 보고서 md파일 작성/`에 저장한다.
7. 작성한 기획 보고서를 바탕으로 PPT를 제작하고 `6. PPT 제작/`에 저장한다.

## 실제 인터뷰 정리 원칙

- 녹음파일을 기준 자료로 삼는다. 질문지는 질문의 맥락과 순서를 확인할 때 사용한다.
- 단순 요약으로 끝내지 않고 아래 여섯 항목으로 정리한다.
- 녹음에서 확인되지 않는 사실을 만들어 넣지 않는다. 불명확한 부분은 표시하고 추가 확인 질문으로 남긴다.
- 실제 참여자의 발언과 분석자의 해석을 분리한다. 가상인물 인터뷰의 답변은 실제 참여자의 발언처럼 인용하지 않는다.

### ① 실제 발언

전사문에서 발언을 그대로 인용하고, 인용마다 발언 ID와 녹음 시간표시를 기록한다.

### ② 상황·행동

언제, 어디에서, 무엇을 했는지 확인 가능한 범위에서 정리한다.

### ③ 불편·장벽

참여자의 행동을 어렵게 만든 조건을 정리한다.

### ④ 명시적 요구

참여자가 직접 원한다고 말한 내용을 정리한다. 관련 발언 ID를 연결한다.

### ⑤ 잠재 니즈

분석자가 발언과 행동을 근거로 해석한 요구를 정리한다. 각 항목에 반드시 **‘해석’**이라고 표시한다.

### ⑥ 추가 확인 질문

현재 자료만으로 알 수 없는 내용을 질문 형태로 정리한다.

## 가상 인터뷰와 브랜딩 기획

- 가상인물의 특성과 답변 중 실제 인터뷰에서 확인된 내용과 추정한 내용을 구분한다. 추정은 가설로 표시한다.
- 브랜딩 기획은 실제 인터뷰에서 확인된 내용을 근거로 작성한다. 가상 인터뷰에서 나온 의견은 검토할 가설로 구분한다.
- 보고서의 주장과 제안은 가능한 한 근거 발언 ID 또는 인터뷰 분석 항목에 연결한다.
- PPT는 완성된 Markdown 기획 보고서의 핵심 논리와 근거를 바탕으로 제작한다.
